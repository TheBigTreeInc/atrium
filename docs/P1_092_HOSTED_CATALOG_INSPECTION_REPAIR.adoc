== Atrium 0.5.48 source changes

* `web/main.mjs`: show configuration/transport errors as separate visible issues in Discover and My Games. True empty-registration text appears only after both catalogs successfully respond and contain zero games. Render messages via textContent, not raw error HTML; remove stale cards on refresh errors. Keep existing reviewed games visible alongside hosted errors.
* `src/hosted_catalog.mjs`: reject reserved documentation-hostnames in hosted gateway configuration; offline `gatewayUrl=""` reports `ATRIUM_HOSTED_NOT_CONFIGURED` rather than a connected empty catalog. Never send bearer/cookies.
* `tools/configure_hosted_catalog.mjs`: before producing a new immutable hosted extension, fetch operator-supplied public gateway anonymously with no redirects, eight-second timeout, and no caching. Require HTTP success, JSON content-type, `Cache-Control: no-store`, `Access-Control-Allow-Origin: *`, valid strict `atrium.hosted-games/v1` schema and >=1 approved active game with resolved trusted launch URLs. Reject unreachable/empty/reserved/invalid endpoints before compiling/staging.
* `extensions/tavi/hosted-release.json`: bump the NEXT hosted extension release to 1.0.6. Immutable published 1.0.5 is not replaced. Default no-gateway builds continue to select historical offline 1.0.4 and do not demote a newer indexed TaviX extension.
* `extensions/tavi/immutable-1.0.4/` and its SHA-256 lock pin the historical 17-file offline extension; normal builds copy it verbatim rather than producing changed 1.0.4 bytes from the evolving shared UI. A real TaviX checkout must still verify these match the original archived 1.0.4.
* Tests use disposable TaviX repositories and an isolated Node preflight fixture (not a production runtime bypass). No actual TaviX checkout is modified during tests.
