= Atrium 0.5.66: complete exact-source Checkers group evidence

== Ownership and reason

The highest-priority suggested ticket `DGN-CHECKERS-M1-AUTOMATED-QA-001` requires game rules, two independent disposable network clients, Social admission rejection and module boundaries to be proven against *the same ZIP bytes*. Prior group evidence covered network/host tests only, with standalone rules and boundary cases run separately by the general Python suite.

This pass extends `tools/checkers_group_qa.py` to use seven required module groups: `tests.test_checkers`, `tests.test_game_contract`, `tests.test_checkers_group_qa`, `tests.test_checkers_trusted_host`, `tests.test_checkers_trusted_routes`, `tests.test_checkers_social_admission`, and `tests.test_checkers_boundary_contract`. The exact-ZIP mode first hashes and extracts the original source ZIP; the subprocess runs the *packaged* suite and modules, not a checkout outside the archive. All missing, duplicated, skipped, failing or under-collected test records fail the group outcome. The evidence includes group names, source module owner, per-group minimum and observed counts, composite source digest, exact archive hash and individual bounded records.

The ownership boundary test asserts the generic Atrium lobby/catalog does not import the Checkers engine, the portable LoopRD rules oracle does not expose a mutable match host, and Tavi/browser clients contain no authoritative server implementation. This is static source coverage; it is not an attestation of running Tavi binaries or any external Social service.
