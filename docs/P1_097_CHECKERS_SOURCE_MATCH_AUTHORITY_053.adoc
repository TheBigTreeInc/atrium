== Source change

`src/checkers_match_authority.py` now owns the reusable persistent Checkers match core, delegating every rule to `src/checkers_adapter.CheckersEngine`. It accepts only trusted canonical subject IDs from a separately authenticated host. The host must authorize both seats and a lobby before calling privileged `create_match`. This source class has *no credential verifier, HTTP route, public listener or active LoopRD registration*. A fixture-only `seed` override is kept in `tests/support/checkers_disposable.py`, not on the production core creation API.

The authority stores match snapshot, monotonic revision and idempotency receipt in SQLite, with `BEGIN IMMEDIATE` transactions to prevent concurrent different-request moves from both succeeding against the same revision across two database connections. `join` is an idempotent seat inspection/resume, not a separate ongoing presence lease. A turn does not depend on either player remaining online.

`tests/support/checkers_disposable.py` is now just a local `127.0.0.1` HTTP transport and fixture identity map over that source authority. Network suite runs 12 groups covering unauthorized join/inspect/move, distinct clients, turn/revision races, replay and changed duplicate, move envelopes, mandatory chained captures, crowning, backward king capture, victory, restart and source-boundary checks. Deterministic fixture SHA and tested-source composite SHA are recorded; a skipped group cannot be counted as passed.
