== Official platform acceptance in CI

The GitHub workflow checks out pinned upstream versions and runs:

[source,shell]
----
python -m looprd validate looprd.yaml
python -m looprd validate examples/sources.local.yaml --sources
python tools/smoke_dapi.py
python _upstream/ziprunner-spec/tools/validate.py package dist/atrium-0.3.0-ziprunner.zip --expected-project atrium --require-verification-plan
----

These commands require the upstream source/checkouts; no bundled validator is
falsely presented as upstream DAPI or ZipRunner. The disposable smoke uses a
temporary data directory, a single component, and no production secrets.

== Activation / release distinction

Installing this ZIP through ZipRunner is source overlay, not automatic DAPI
activation, schema migration, Git commit or release approval. The operator
must explicitly review the Git changes, validate the real DAPI component,
register the source after a safe backup, and observe the running API. Production
Social/Tavi integration and dynamic app publishing are future milestones.
