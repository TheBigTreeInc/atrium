== New game-owned method

`src.checkers_match_authority.CheckersMatchAuthority.legal_actions(match_id, canonical_subject)` exposes *only* this game's server-owned legal paths to the actor whose turn it is. Return fields are exactly `protocol=atrium.checkers.actions/v1`, `matchId`, `revision`, `seat`, `turn`, and `actions` (array of complete paths). The authenticated nonmoving participant gets an empty list; an unknown/outside subject gets a 404/403 error. No participant identifiers, fixture tokens, database handles or opponent actions are exposed.

The method delegates exclusively to the module-owned `CheckersEngine`, protects the read with the authority lock, and does not mutate SQLite. The method accepts canonical, already authenticated identities from a **trusted host only**: no browser body/query parameter may supply its `subject` or create a match. `create_match` remains privileged and requires two distinct host-approved subjects. Requests must retain the exact `revision` and unique `requestId` for idempotent move retries.
