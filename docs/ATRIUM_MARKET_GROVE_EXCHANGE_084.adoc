== Source baseline and scope

0.5.84 is a source candidate layered over the Library `Atrium/Latest/atrium-0.5.83-ziprunner.zip` snapshot (not a verified newer Git commit). Preserve authoritative checkout and reconcile against main before production. Only Atrium source files change: `games/market-grove/game/engine.py`, the new `exchange_extensions.py`, separate child `looprd.base.yaml`, generated `looprd.yaml`, source generator, game web UI, reference import utility, tests and documentation, plus exact ZipRunner release metadata. No TaviX `.tavix` binary or Tavi Wallet implementation is modified.

== Implemented

* Market Grove remains a hosted Atrium game discovered from `games/market-grove/atriumd.yaml` under root Atrium LoopRD source; separate `market-grove` service auth/storage, not root includes.
* 44 finite game instruments (26 fictional equities, 12 commodity-inspired, 6 FX-inspired) in one SQLite child DB, not separate apps or currencies.
* 20 bot strategies across 200 persistent deterministic practice accounts; one coordinated scheduler tick per auction, not 20 competing scheduled jobs.
* Maximum-volume, uniform-price player-to-player matching with no self-fills, then residual finite maker trades; all trades settle game-owned practice funds atomically and respect limits/reservations.
* A shared price and daily-reference anchor, provenance, premium basis points, bounded movements and idempotent, operator-only reference ingestion (`market:reference`). Optional external reference importer with fixed official ECB endpoint and offline vetted JSON input; source does not auto-enable network fetching.
* New databases default to five-minute auctions; older source databases keep their existing (hourly) immutable interval. The 60-second job only ticks due periods and cannot replay a completed auction.
* Responsive Market Grove UI now filters fictional equities/commodities/FX and shows the reference premium and global market quote; the operator-only preview still requires a short-lived Market Grove child key, not a Tavi sign-in.

== Rebuild and QA

[source,shell]
----
python tools/build_market_grove_spec.py --check
python tools/check_specs.py
python -m unittest discover -s tests -v
npm test
npm run build
npm run verify
python tools/package_zip.py
----

`tools/market_grove_reference_import.py` default behavior displays JSON without submitting any request. For operator-vetted JSON, run `python tools/market_grove_reference_import.py --file APPROVED.json`. For optional official daily ECB references, run `python tools/market_grove_reference_import.py --ecb`. To submit after *separate grant and provenance approval* set `MARKET_GROVE_REFERENCE_TOKEN` in an ephemeral operator environment, provide HTTPS child URL and pass `--apply --base-url ...`. **Never** place tokens in source or a browser. EIA API key and licensed metals feeds require separately approved operator fetch jobs; do not invent data or inject an unrestricted third-party endpoint. Sources: https://data.ecb.europa.eu/help/api/data-examples ; https://www.eia.gov/opendata/documentation.php . The external observations represent relative movement only; no underlying spot assets or physical commodities are bought.
