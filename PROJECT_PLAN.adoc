= Atrium Project Plan
:revnumber: 0.4.0
:toc: left

== Product intent
Independent browser/Tavi-accessible app and classic-games ecosystem with a dynamic registry, reusable game engine, social access and clearly labeled Staff opponents. Looprd defines the component format and DAPI executes it.

== Current outcome
P0 v0.3.0 foundation is present in the GitHub repository. P1 v0.4.0 provides the first persistent, scoped, operator-reviewed app registry in source. It is an incremental candidate update to ZipRunner project `atrium`, *not* a deployed release.

== Lifecycle rules
Development reports describe source evidence only. ZipRunner's trusted verification and the operator's real acceptance tests govern the managed task state. The operator must approve push, release, migration and deployment separately. Historic tasks must be retained by their original IDs; build failure never marks work Done.
