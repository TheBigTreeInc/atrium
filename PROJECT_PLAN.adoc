== Planning rules
* Planning is advisory and does not implement or approve work.
* New ideas enter Suggested and require an operator or design-bounded policy decision before To do.
* ZipRunner owns managed To do → In progress → Manager/QA assessment transitions.
* Manager/QA is authoritative for technical acceptance and may expose approved completed work to operator Review.
* The operator tests the installed behavior and alone marks the task Done or sends it back with direction.
* Keep work items bounded and independently verifiable.
